# Site do ScrapCade

Página do [ScrapCade OS](https://github.com/thiagotechmaker/scrapcade.os) e do [fliperama do iChroma](https://github.com/thiagotechmaker/scrapcade-fliperama), em português e inglês: **https://thiagotechmaker.github.io/scrapcade/**

HTML, CSS e um JavaScript pequeno (idioma e link da versão mais nova), sem build. Para ver no PC: `python -m http.server` nesta pasta e abrir `http://localhost:8000/scrapcade/`.

Código sob GPLv3, como os projetos. Capas de jogos nas capturas são dos seus donos.
